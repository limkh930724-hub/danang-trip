# 다낭 가족여행 일정표

2026년 9월 5일부터 9일까지, 어른 넷이 다낭에 갑니다.
현지에서 휴대폰으로 꺼내보는 일정표입니다.

파일 하나(`index.html`)로 끝나며 외부 라이브러리·폰트·CDN·이미지 요청이 없습니다.
비행기 안이나 데이터가 없는 곳에서도 사진까지 그대로 뜹니다.
인터넷이 필요한 건 지도 버튼뿐입니다.

## 헤더

맨 위는 화면에서 살짝 떠 있는 노란 카드입니다. 제목과 두 시계 아래에 흰 알약 버튼이
가로로 놓이고(환율 · 지금 일정 · 앱 설치), 카드 바닥은 골든브릿지 사진 띠로 닫힙니다.

- **환율** — 환율 계산기 팝업. 예전에는 일정 탭 위의 초록 버튼이었지만 헤더로 옮겼습니다
- **지금 일정** — 어느 탭에 있든 오늘 일정의 "지금" 자리로 데려다줍니다
- **앱 설치** — 설치할 수 있을 때만 나옵니다. 자세한 규칙은 아래 "설치" 참고

## 화면

| 탭 | 하는 일 |
|---|---|
| **일정** | 맨 위 요약 카드가 진행 중인 일정과 다음 일정을 보여주고, 그 아래가 시간대별 타임라인입니다. 여행 기간에 열면 오늘 날짜가 자동 선택되며 현재 시각 위치에 황동빛 선이 그어집니다. **좌우로 밀면 날짜가 넘어갑니다** |
| **예약** | 항공·숙소 정보. 번호를 눌러 복사, 비상 연락처는 눌러 전화 |
| **장소** | 지역·숙소·식당·그 밖에 네 갈래. 구글맵 바로가기와 베트남어 주소를 전체화면으로 띄우는 "기사님께 보여주기" |
| **준비물** | 체크리스트. 체크 상태는 브라우저에 저장되어 다시 열어도 남습니다 |

## 손으로 다루기

- **날짜 넘기기** — 날짜 바를 눌러도 되고, 일정 화면을 좌우로 밀어도 됩니다.
  미는 동안 옆 날짜가 실제로 붙어 손가락을 따라오고, 손을 떼면 남은 거리만 굴러갑니다.
  절반도 못 밀고 놓으면 제자리로 돌아오고, 첫날·마지막날에서는 고무줄처럼 조금만 따라옵니다.
  가로로 스크롤되는 줄(날짜 바, 헤더 알약, 장소 하위 탭) 위에서는 밀어도 넘어가지 않습니다
- **맨 위 · 맨 아래로** — 스크롤하는 동안 오른쪽 아래에 화살표 두 개가 뜹니다.
  손을 떼고 1.5초가 지나면 사라져 일정 카드를 가리지 않습니다.
  이미 맨 위면 위 화살표가, 맨 아래면 아래 화살표가 빠집니다

## 여행 정보 고치는 법

`index.html`의 `<script>` 안에 있는 **`TRIP` 객체 한 군데만** 고치면 됩니다.
HTML이나 CSS는 건드릴 필요가 없습니다.

```js
const TRIP = {
  title: "다낭 가족여행",
  people: "어른 4명 · 2객실",
  nights: "3박 5일",
  days: [ ... ],        // 날짜별 일정
  bookings: [ ... ],    // 예약 정보
  emergency: [ ... ],   // 비상 연락처
  placeGroups: [ ... ], // 장소 목록
  checklist: [ ... ],   // 준비물
  facts: [ ... ],       // 알아두면 편한 것
  phrases: [ ... ]      // 베트남어 한마디
};
```

일정 한 줄의 생김새:

```js
{
  time: "09:30",              // 24시간 표기
  kind: "관광",                // 이동 / 관광 / 식사 / 휴식 / 숙소
  title: "미케비치 산책",
  vi: "Bãi biển Mỹ Khê",       // 현지 이름 (없으면 "")
  note: "호텔에서 걸어갈 거리",   // 메모 (없으면 "")
  map: "Bãi biển Mỹ Khê",      // 지도 검색어 (없으면 지도 버튼이 안 나옴)
  thumb: "beach",             // 76px 썸네일. PHOTOS의 키
  photo: "mt",                // 카드 위 큰 사진. 숙소에만 씀
  nextDay: true               // 자정을 넘긴 일정일 때만
}
```

날짜를 바꿀 때는 `date`(`YYYY-MM-DD`)와 `dow`(요일 한 글자)를 함께 맞춰주세요.
`dow`는 화면에 그대로 나오는 글자라 자동으로 계산되지 않습니다.

> 항공편과 숙소는 확정된 실제 정보입니다.
> 예약번호는 뒷자리만 적혀 있습니다. 아래 "공개 배포 시 주의"를 봐주세요.

## 사진

`PHOTOS` 객체에 모여 있고, 전부 위키미디어 커먼즈의 자유 라이선스 이미지를
WebP로 줄여 파일에 직접 넣었습니다. 외부 요청이 없어 오프라인에서도 보입니다.

- `wide: 1` 은 카드 위를 가로로 채우는 큰 사진입니다. 숙소 두 곳에만 씁니다.
- `wide: 0` 은 76px 정사각 썸네일입니다. 나머지 전부에 씁니다.

어디서 자는지는 크게, 어디를 가는지는 작게 보면 된다는 기준입니다.

식당은 가게 외관 대신 **그 집에서 먹는 음식** 사진을 넣었습니다. 외관보다
무엇을 파는지가 고를 때 도움이 되고, 자유 라이선스 사진도 음식 쪽이 훨씬 많습니다.
미꽝 1A 와 모닝글로리만 실제 그 가게 사진입니다.

CC 라이선스는 저작자 표기를 **법적으로 요구합니다.** 지우면 안 됩니다.
대신 페이지 맨 아래에 접어두어 평소에는 "사진 출처" 한 줄만 보입니다.
목록은 `PHOTOS`를 읽어 자동으로 만들기 때문에 사진을 더해도 따로 손볼 필요가 없습니다.

## 색

"손트라의 그늘"이라는 이름으로 잡은 숲 팔레트입니다.
베트남 옻칠(sơn mài)의 짙은 옥빛과 금박을 뼈대로 삼았습니다.

| 역할 | 토큰 | 설명 |
|---|---|---|
| 배경 | `--paper` | 거의 순백(#FBFBFA). 초록기를 뺀 중립색입니다 |
| 카드 | `--card` | 순백. 배경보다 밝아 그림자 없이도 떠 보입니다 |
| 본문 | `--ink` | 짙은 숲 |
| 구조 | `--sea` | 옻칠 옥빛. 선택된 날짜, 버튼, 활성 탭 |
| 헤더 | `--sunny` | 노란 색면 카드. 그 아래에 바나힐 골든브릿지 사진(`--hero`) 띠가 붙습니다 |
| **지금** | `--sun` | **황동빛. 잎 사이로 든 빛이자 옻칠의 금박** |

종류별 색은 강물(이동), 잎사귀(관광), 옻칠(식사), 나무껍질(휴식·숙소)입니다.

헤더 노랑(`--sunny`)과 황동빛(`--sun`)은 다른 색입니다. 헤더는 넓은 색면이고
황동빛은 흰 카드 위의 작은 표시라 한 화면에서 섞이지 않습니다.

**황동빛(`--sun`)은 지금 이 순간에만 씁니다.** 현재 시각 표시, 진행 중인 일정 카드,
요약 카드 테두리 이 세 곳뿐입니다. 다른 곳에 쓰면 지금이 어디인지 눈에 안 들어옵니다.

## 재료

요소마다 재료를 다르게 씁니다. 전부 테두리 두른 둥근 상자로 만들면
어디가 중요한지 알 수 없게 됩니다.

- **카드**: 낮에는 테두리 없이 면과 그림자로만 뜹니다. 밤에는 그림자가 안 보이므로
  `--card-edge` 로 아주 얇은 선만 둡니다.
- **버튼**: 외곽선 없이 톤으로 채웁니다(`--tonal`). 주요 동작만 진한 면(`--sea`)입니다.
- **날짜**: 상자가 아니라 글자입니다. 고른 날 아래에만 밑줄이 그어집니다.
- **일정 탭의 상자는 헤더와 같은 노란 실선(`--sunny`)을 두릅니다.** 1px 얇은 선이고,
  진행 중인 일정만 2.5px로 굵어집니다. 예약·장소·준비물 카드는 여전히 선 없이
  면과 그림자로만 뜹니다.

**기본은 밝은 쪽입니다.** 기기가 다크 모드여도 밝게 시작합니다.
헤더 오른쪽 위 해/달 버튼을 누르면 밤의 숲으로 바뀌고, 그 선택은 폰에 남습니다.

색 값은 `--d-*` 원본 한 벌에 모여 있고 `:root[data-theme="dark"]`가 매핑만 바꿉니다.
색을 고칠 때 한 곳만 손보면 됩니다.

## 확인된 동작

- 본문과 보조 텍스트 대비 **WCAG AAA**. 라이트 최저 7.22:1, 다크 최저 7.22:1
- 가장 작은 글자 12px, 모든 터치 영역 40px 이상
- 아이폰 노치·홈바 영역 대응 (`safe-area-inset`)
- 밝게/어둡게 수동 전환, 선택은 `localStorage`에 저장
- `prefers-reduced-motion` 존중
- 하단 탭은 `tablist`/`tab`/`tabpanel`. 좌우 화살표로도 옮겨지고
  스크린리더가 "4개 중 2번째"로 읽습니다
- 팝업(환율 · 설치 안내 · 기사님 화면)은 열려 있는 동안 탭 키가 안에서 돌고,
  닫으면 열 때 눌렀던 자리로 포커스가 돌아갑니다
- 외부 네트워크 요청 0건

## 공개 배포 시 주의

이 저장소는 GitHub Pages로 배포됩니다. **주소를 아는 사람은 누구나 페이지를 볼 수 있습니다.**
저장소를 비공개로 바꿔도 Pages로 배포된 페이지 자체는 공개입니다.

`TRIP.bookings`에 아래 값의 **전체**를 적지 마세요. 뒷자리만 남기고 전체는 가족 단톡방에 두세요.

- 예약번호 / 바우처 번호. 남이 예약을 취소하거나 변경할 수 있습니다
- 예약자 영문 이름, 아고다 회원번호
- 기사·가이드 개인 휴대폰 번호. 제3자의 개인정보입니다
- 여권번호, 카드번호, 주민등록번호. 어떤 경우에도 넣지 않습니다

호텔 대표번호, 총영사관, 긴급번호(113/115)는 공개된 정보라 그대로 둬도 됩니다.

메모용 실제 번호는 `private/` 폴더에 두면 커밋되지 않습니다 (`.gitignore`에 등록됨).

### 남아있는 노출
