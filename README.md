# 다낭 가족여행 일정표

가족이 현지에서 휴대폰으로 꺼내보는 여행 일정표입니다.
파일 하나(`index.html`)로 끝나며, 외부 라이브러리·폰트·CDN을 쓰지 않습니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| **일정** | 시간대별 세로 타임라인. 여행 기간에 열면 오늘 날짜가 자동 선택되고, 현재 시각 위치에 주황색 마커가 그어집니다 |
| **예약** | 항공·숙소·차량·투어 예약번호. 번호를 눌러 복사, 비상 연락처는 눌러 전화 |
| **장소** | 구글맵 바로가기 + 베트남어 주소를 전체화면으로 크게 띄우는 "기사님께 보여주기" |
| **준비물** | 체크리스트. 체크 상태는 브라우저에 저장되어 다시 열어도 남습니다 |

## 여행 정보 고치는 법

`index.html`의 `<script>` 맨 위에 있는 **`TRIP` 객체 한 군데만** 고치면 됩니다.
HTML이나 CSS는 건드릴 필요가 없습니다.

```js
const TRIP = {
  title: "다낭 가족여행",
  people: "어른 2 · 아이 2",
  nights: "3박 5일",
  days: [ ... ],        // 날짜별 일정
  bookings: [ ... ],    // 예약 정보
  emergency: [ ... ],   // 비상 연락처
  placeGroups: [ ... ], // 장소 목록
  checklist: [ ... ],   // 준비물
  facts: [ ... ],       // 알아두면 편한 것
  phrases: [ ... ]      // 베트남어 한마디
};
```

일정 한 줄의 생김새:

```js
{
  time: "09:30",              // 24시간 표기
  kind: "관광",                // 이동 / 관광 / 식사 / 휴식 / 숙소
  title: "미케비치 산책",
  vi: "Bãi biển Mỹ Khê",       // 현지 이름 (없으면 "")
  note: "파라솔·튜브 대여 가능",  // 메모 (없으면 "")
  map: "Bãi biển Mỹ Khê",      // 지도 검색어 (없으면 항목 생략)
  nextDay: true                // 자정을 넘긴 일정일 때만
}
```

날짜를 바꿀 때는 `date`(`YYYY-MM-DD`)와 `dow`(요일 한 글자)를 함께 맞춰주세요.
`dow`는 화면에 그대로 표시되는 글자라 자동으로 계산되지 않습니다.

> 현재 들어있는 날짜·항공편명·예약번호는 모두 **예시**입니다.

## 열어보기

`index.html`을 더블클릭하면 그대로 열립니다.
휴대폰에 저장해두면 비행기 안이나 데이터가 없는 곳에서도 열립니다.
인터넷이 필요한 건 지도 버튼뿐입니다.

## 확인된 동작

- 아이폰 노치·홈바 영역 대응 (`safe-area-inset`)
- 시스템 다크모드 자동 전환
- 본문 대비비 약 14:1, 모든 터치 영역 42px 이상
- `prefers-reduced-motion` 존중
