# 다낭 가족여행 일정표

가족이 현지에서 휴대폰으로 꺼내보는 여행 일정표입니다.
파일 하나(`index.html`)로 끝나며, 외부 라이브러리·폰트·CDN을 쓰지 않습니다.

## 화면

| 탭 | 하는 일 |
|---|---|
| **일정** | 시간대별 세로 타임라인. 여행 기간에 열면 오늘 날짜가 자동 선택되고, 현재 시각 위치에 주황색 마커가 그어집니다 |
| **예약** | 항공·숙소·차량·투어 예약번호. 번호를 눌러 복사, 비상 연락처는 눌러 전화 |
| **장소** | 구글맵 바로가기 + 베트남어 주소를 전체화면으로 크게 띄우는 "기사님께 보여주기" |
| **준비물** | 체크리스트. 체크 상태는 브라우저에 저장되어 다시 열어도 남습니다 |

## 여행 정보 고치는 법

`index.html`의 `<script>` 맨 위에 있는 **`TRIP` 객체 한 군데만** 고치면 됩니다.
HTML이나 CSS는 건드릴 필요가 없습니다.

```js
const TRIP = {
  title: "다낭 가족여행",
  people: "어른 2 · 아이 2",
  nights: "3박 5일",
  days: [ ... ],        // 날짜별 일정
  bookings: [ ... ],    // 예약 정보
  emergency: [ ... ],   // 비상 연락처
  placeGroups: [ ... ], // 장소 목록
  checklist: [ ... ],   // 준비물
  facts: [ ... ],       // 알아두면 편한 것
  phrases: [ ... ]      // 베트남어 한마디
};
```

일정 한 줄의 생김새:

```js
{
  time: "09:30",              // 24시간 표기
  kind: "관광",                // 이동 / 관광 / 식사 / 휴식 / 숙소
  title: "미케비치 산책",
  vi: "Bãi biển Mỹ Khê",       // 현지 이름 (없으면 "")
  note: "파라솔·튜브 대여 가능",  // 메모 (없으면 "")
  map: "Bãi biển Mỹ Khê",      // 지도 검색어 (없으면 항목 생략)
  nextDay: true                // 자정을 넘긴 일정일 때만
}
```

날짜를 바꿀 때는 `date`(`YYYY-MM-DD`)와 `dow`(요일 한 글자)를 함께 맞춰주세요.
`dow`는 화면에 그대로 표시되는 글자라 자동으로 계산되지 않습니다.

> 현재 들어있는 날짜·항공편명·예약번호는 모두 **예시**입니다.

## 열어보기

`index.html`을 더블클릭하면 그대로 열립니다.
휴대폰에 저장해두면 비행기 안이나 데이터가 없는 곳에서도 열립니다.
인터넷이 필요한 건 지도 버튼뿐입니다.

## 색

 라는 이름으로 잡은 따뜻한 팔레트입니다.
오트빛 벽(), 우유거품 같은 카드(), 에스프레소 글자()에
딥 커피()가 구조를 잡습니다.

**햇살색()은 지금 이 순간에만 씁니다.** 현재 시각 표시, 진행 중인 일정 카드,
요약 카드 테두리 이 세 곳뿐입니다. 다른 곳에 쓰면 지금이 어디인지 눈에 안 들어옵니다.

헤더와 요약 카드의 빛은 둘 다 오른쪽 위에서 들어옵니다. 광원이 하나라는 뜻이라
방향을 바꾸지 마세요.

밤에는 같은 카페의 램프 불빛으로 바뀝니다 (시스템 다크모드 자동 감지).

## 확인된 동작

- 아이폰 노치·홈바 영역 대응 (`safe-area-inset`)
- 시스템 다크모드 자동 전환
- 본문 대비비 약 14:1, 모든 터치 영역 42px 이상
- `prefers-reduced-motion` 존중

## 공개 배포 시 주의

이 저장소는 GitHub Pages로 배포됩니다. **주소를 아는 사람은 누구나 페이지를 볼 수 있습니다.**
저장소를 비공개로 바꿔도 Pages로 배포된 페이지 자체는 공개입니다.

`TRIP.bookings`에 아래 값의 **전체**를 적지 마세요. 뒷자리만 남기고 전체는 가족 단톡방에 두세요.

- 예약번호 / 바우처 번호 — 남이 예약을 취소하거나 변경할 수 있습니다
- 기사·가이드 개인 휴대폰 번호 — 제3자의 개인정보입니다
- 여권번호, 카드번호, 주민등록번호 — 어떤 경우에도 넣지 않습니다

호텔 대표번호, 총영사관, 긴급번호(113/115)는 공개된 정보라 그대로 둬도 됩니다.

메모용 실제 번호는 `private/` 폴더에 두면 커밋되지 않습니다 (`.gitignore`에 등록됨).

### 남아있는 노출

민감 정보를 빼도 **일정표 자체가 "9/24–9/28 집이 빈다"는 사실을 알려줍니다.**
검색 노출은 `<meta name="robots" content="noindex, nofollow">`로 막아뒀지만,
주소를 아는 사람에게는 그대로 보입니다. 신경 쓰인다면 저장소 이름을
추측하기 어려운 이름으로 바꾸거나, Cloudflare Pages + 이메일 인증으로
가족만 접근하게 하는 방법이 있습니다.
